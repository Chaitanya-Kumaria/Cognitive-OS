# Development Roadmap

This roadmap describes the long-term direction, not an implementation commitment. A phase should begin only when the preceding work has established a concrete need and its privacy, quality, and evaluation criteria.

## Phase 0 — Foundation

Establish the repository, architecture, evolving ontology, draft schemas, Git defaults, privacy boundaries, and engineering backlog. **Current phase.**

## Phase 1 — Knowledge ingestion

Ingest PDFs, presentations, documents, and other learning material while preserving originals, source identity, and useful page/slide/section locations.

## Phase 2 — Knowledge extraction

Extract concepts, frameworks, principles, methods, examples, and claims. Distinguish source statements from inferences and retain claim-level provenance.

## Phase 3 — Knowledge graph

Create explicit, meaningful, evidence-aware relationships between knowledge objects; represent disagreement without overwriting either side.

## Phase 4 — Retrieval

Explore hybrid retrieval that combines semantic, lexical, and graph-based signals. Evaluate usefulness before selecting storage or indexing infrastructure.

## Phase 5 — Reasoning

Provide relevant, traceable knowledge to a model and ask it to reason over that evidence with explicit assumptions, uncertainty, and citations.

## Phase 6 — Applicability engine

Given a problem or situation, identify potentially relevant concepts and frameworks from the knowledge base and explain why they may apply.

## Phase 7 — Personal memory

Represent experiences, decisions, outcomes, beliefs, preferences, and reflections with appropriate context, time, and provenance.

## Phase 8 — Personal reasoning model

Explore how the owner approaches problems and makes decisions, based on explicit evidence rather than unreviewed profiling or unsupported generalization.

## Phase 9 — Reflection and learning

Learn from corrections, outcomes, and changed beliefs while preserving prior versions and the reasons for change.

## Phase 10 — Evaluation

Build representative benchmarks and review workflows that test whether the system is a useful, trustworthy second brain, including provenance, calibration, retrieval quality, and privacy behavior.
